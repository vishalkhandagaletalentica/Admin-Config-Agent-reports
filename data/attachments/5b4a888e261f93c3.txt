Subtask List (Task Mgr) settings:
- Column Order — Column order in the report
- Display Remaining Duration For NS Subtasks — Display Remaining Duration for Not Started Subtasks
- Default Horizon — Number of time intervals (default 30 days)
- Rows Per Page — Rows per page
- Sort By Priority Fields Within Windows Of — Window size for grouping priority fields
- Filters Available — Filter names to show in Advanced Filtering
- Filters To Display — Default filters to display in the report
- Hidden Fields — Columns hidden in report
- Hidden Fields (Print) — Columns hidden in Print Preview
- Print Font Size — Default font size used in Print Preview
- Sort Order — Default sorting order (multiple columns allowed)
- Display separator after each Sort Window — Show separator after each sort window
- Task Status Filter — Default Task Status Filter
